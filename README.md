# pair-wise-yy-60 碳减排项目监测证据核验与签发准备平台

按监测周期完成活动数据、排放因子、证据来源、异常波动和计算链核验。支持抽样任务、版本化数据修订、发现项闭环和签发前完整性检查。

## 版本链与并发机制

记录核验、发现项处理、签发准备绑定在同一条监测期版本链上（`lib/domain.ts`）：

- **乐观并发**：记录级变更携带打开页面时的版本号（`baseRevision`）提交，先到者得；版本不一致时服务端返回 409 与最新值，客户端保留冲突副本，可基于最新版本重新提交，不会覆盖他人修订。
- **级联失效**：活动数据一变，数据纪元（`dataEpoch`）+1——旧核验结果与抽样统计失效重算，关联发现项退回处理，签发门禁按新纪元重算；存在未完成项时提交被拦截并列出缺口。
- **断网重试**：变更经客户端 outbox 顺序写入，每条携带幂等键 `clientId`；批次中途断网只重试未确认记录，已生效数据与服务端版本保留，重试不会重复写入。顶栏可切换"模拟断网"进行验证。

## 技术栈

Next.js App Router、MUI、Zustand、ky、Zod、TypeScript。

## 运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62060`。`/api/evidence` 提供监测期状态的 GET/POST 接口（内存态，重启即重置为种子数据）。顶栏可切换操作端身份（现场端/复核端），开两个浏览器标签即可模拟双端并发保存。

```bash
npm run build
```
